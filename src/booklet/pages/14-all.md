<div class="fp"><b>第一性原理</b>　急性白血病的診斷骨架只有一套：<b>臨床 → 骨髓 → flow 定 lineage → cytogenetics／分子</b>。AML 與 ALL 差在後兩步的分層工具與藥物組合——ALL 的第一個分岔永遠是 <b>Philadelphia chromosome（BCR-ABL1）陽性與否</b>，它直接決定要不要加 TKI。</div>

## MECE 分岔

| 層 | 問什麼 | 分支（互斥、窮盡） | 決定了什麼 |
| --- | --- | --- | --- |
| 1 診斷 | 是哪一系？ | 型態＋MPO 初篩 → flow：myeloid vs B／T lymphoid | 型態曖昧不硬猜，先染色、再聯絡 flow |
| 2 分層 | Ph 陽性還是陰性？ | 陽性 → 化療 + TKI；陰性 → 純化療多階段；其餘標記（KMT2A 重排、hypodiploidy）為次要分層 | 成人 ALL 治療分流的第一個分岔 |
| 3 強度 | 緩解後要不要移植？ | 成人：達 CR 後積極評估 allo-HCT（不論 Ph）；兒童：以化療為主、移植保守 | 年齡層改變移植角色的權重 |

## 型態不確定時，每個工具能回答什麼

| 工具 | 能回答 | 不能回答／下一步 |
| --- | --- | --- |
| 骨髓抹片型態 | Blast 比例與型態，形成初步印象 | 有時無法可靠分 myeloid／lymphoid；曖昧不要硬猜 |
| MPO 染色 | 陽性支持 myeloid（傾向 AML）；主動請病理加做，常是更快先做的一步 | 陰性只代表不能排除 lymphoid，不等於排除 AML |
| Flow cytometry | 用表面標記拍板 lineage，是分辨 AML／ALL 最直接且決定性的工具 | 要**口頭**聯絡實驗室說明是型態不確定的緊急個案，請優先處理 |

## Philadelphia chromosome：三個問法、三個答案

| 被問到 | 正確答案 | 一句話理由 |
| --- | --- | --- |
| t(9;22)／BCR-ABL1 最典型對應哪個病 | CML 慢性期 | 定錨點，從 AML 側或 ALL 側被問都先講 |
| BCR-ABL1 陽性的急性白血病，AML 還是 ALL 常見 | **ALL 遠比 AML 常見** | 與「Ph 聽起來急、應該是 AML」的直覺相反，最常答反 |
| 成人 ALL 陽性比例 | 約 25–30%，隨年齡上升（補充） | 比例不低，且直接決定要不要加 TKI，重要性甚至高於在 AML |

## 依 Ph 狀態決定的治療路徑

| 分型 | 治療骨幹 | 緩解後 | 補充 |
| --- | --- | --- | --- |
| Ph+ ALL | 化療骨幹外加 TKI（imatinib、dasatinib；ponatinib 為新一代選項），針對 BCR-ABL1 融合蛋白提升緩解率與深度 | 積極評估並安排 allo-HCT | TKI 在 ALL 是搭配化療，不像 CML 單獨當主治療 |
| Ph− ALL | 純化療多階段：induction → consolidation → maintenance，不常規加 TKI | 仍要評估 allo-HCT 角色 | 高風險特徵（KMT2A、hypodiploidy、MRD+）傾向移植 |
| 兒童 ALL（對比） | 以化療為主 | 移植角色相對保守 | 成人預後較差、復發風險高，所以態度更積極 |
| MRD 引導（補充） | 誘導後 MRD 是最強預後因子；MRD+ 可用 blinatumomab 清除 | MRD+ 者傾向 allo-HCT | Blinatumomab（CD19 BiTE）、inotuzumab（CD22 ADC）為復發／難治後線 |
| CNS 預防（補充） | 所有 ALL 均需 intrathecal chemo（MTX ± cytarabine） | — | ALL 與 AML 治療的另一個結構性差異 |

## 破題關鍵句

| 題 | 一開口就講 |
| --- | --- |
| 型態不確定 | 「型態不確定時我不猜，我主動請病理科加做 MPO 染色、同時電話通知 flow 優先處理。」 |
| t(9;22) 常見度 | 「BCR-ABL1 陽性的急性白血病裡，ALL 遠比 AML 常見——這跟直覺相反，千萬不要答反。」 |
| Ph+ ALL 治療 | 「BCR-ABL1 陽性就加 TKI，緩解後就積極評估 allo-HCT——兩個獨立但連續的決策點，不混成一句『積極治療』。」 |
| 成人 vs 兒童 | 「成人 ALL 整體預後較差、復發風險高，所以移植態度比兒童積極。」 |
| Ph− 怎麼走 | 「走 induction、consolidation、maintenance 的多階段化療，不常規加 TKI，但緩解後仍要評估移植。」 |

## 容易被電

- 把 t(9;22) 的常見度答反成「AML 比較常見」——與 AML 篇同一題，只是問法反過來，前後答案不能矛盾。
- 型態不確定就跳去講治療，漏掉「先染色、再聯絡 flow 確認 lineage」的處置流程。
- MPO 陰性就說「一定是 ALL」——陰性只是不支持 myeloid，最終仍靠 flow。
- 只講「Ph+ 要加 TKI」，講不出成人緩解後移植這一段，治療路徑只講一半。
- 把 ALL 當成要重新背一套骨架——它是同一套「確認診斷→分層→決定強度」換分層工具而已。
