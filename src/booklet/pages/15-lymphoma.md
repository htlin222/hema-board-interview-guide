<div class="fp"><b>第一性原理</b>　每一線的選擇都是<b>「疾病生物學／時間點」給的</b>，不是藥名清單：一線由分期＋IPI 給、二線由復發時間點給、三線由證據＋給付給。反應差時，<b>先問診斷對不對，再問要不要換藥</b>——分數不支持效果差，就是要回頭質疑診斷的訊號。</div>

## DLBCL 一路到後線，每一線靠什麼決定

| 治療線 | 分岔問題 | 分支（互斥、窮盡） | 一定要主動講 |
| --- | --- | --- | --- |
| 一線 | 分期＋IPI 給多強？ | 依風險分層選 regimen；標準 R-CHOP，Pola-R-CHP 在 IPI 2–5 有 PFS 優勢（補充） | 「分數不高、分期不晚」常是後續劇情的伏筆 |
| 反應差（PR 未 CR） | 診斷對不對？ | 分數不支持效果差 → review 病理是否更 aggressive 亞型、補 FISH 排除 double／triple-hit；診斷確定 → PR 視為 refractory | 先懷疑資料，再懷疑藥 |
| 二線 | 復發距一線 ≤12 個月？ | **早期復發／未達 CR 且適合 CAR-T** → 直接 CAR-T（axi-cel ZUMA-7、liso-cel TRANSFORM）；**晚期復發** → salvage 化療誘導 → auto-PBSCT | BELINDA（tisa-cel）未顯示優勢，效益是特定產品才有 |
| 三線以後 | 證據＋給付？ | CAR-T、bispecific antibody、ADC（polatuzumab） | 藥證核准 ≠ 健保給付：做過 auto-transplant 可能不符給付資格 |

## Salvage regimen：講名字、講反應率，講「不是都走得到移植」

| Regimen | 組成 | 試驗 ORR |
| --- | --- | --- |
| R-ICE | rituximab + ifosfamide + carboplatin + etoposide | CORAL 64% |
| R-DHAP | rituximab + dexamethasone + high-dose cytarabine + cisplatin | CORAL 63%；LY.12 45% |
| R-GDP | rituximab + gemcitabine + dexamethasone + cisplatin | LY.12 44% |
| 整體 | 約四到六成五，別隨口講「六到七成」 | 只有約**一半**病人反應夠好而真正走到 auto-PBSCT；治療階段就要評估收 stem cell |

## Follicular lymphoma：先問「該不該動手」

| 情境 | 判斷 | 處置 |
| --- | --- | --- |
| 原發腸胃道（duodenum／small intestine）、無症狀 | 侷限、低腫瘤負荷，不符 GELF 啟動標準 | Watch and wait，不因看到 lymphoma 就急著治 |
| 廣泛期或合併 B symptoms | 符合 GELF | 啟動一線 |
| GELF 啟動標準 | 任一：腫瘤 ≥7 cm；≥3 處 ≥3 cm；B symptoms；脾腫大；壓迫／積液；血球低下；LDH 或 β2M 上升（補充切點） | 核心：負荷夠大或有症狀才治 |
| 一線選藥 | 依年紀、共病、腫瘤負荷 | BR（血液學毒性較輕，常優先）或 R-CHOP |

## 其他常見延伸

| 題 | 答法 |
| --- | --- |
| Asymptomatic lymphocytosis | 先完整 H&P 排除感染／反應性原因 → 再送周邊血 flow（CD5、CD23）看是否 CLL → 確診 CLL 也不一定治療，指徵邏輯類似 GELF（低負荷無症狀觀察） |
| WHO 分類版本差異 | 講方向不背細項：從型態學為主 → 2008 後整合分子／免疫表型／臨床特徵定義 disease entity |
| Lymphoma 移植時機 | 機構間差異大（提早做 vs 藥物用盡才做），考官要的是「沒有絕對對錯」的概念，不是單一標準答案 |
| Hodgkin（補充） | 常被拿來對照問：年輕雙峰、頸部無痛淋巴腫、B symptoms、Reed-Sternberg cell、ABVD 為一線 |

## 破題關鍵句

| 題 | 一開口就講 |
| --- | --- |
| 分期／IPI 給了 | 「分期跟 IPI 不是拿來背方案名字的，是決定起手治療強度的分層依據。」 |
| PR 未達 CR | 「IPI 分數不支持治療效果差的時候，我要先回頭懷疑診斷，不是先換藥。」 |
| 二線怎麼選 | 「第一個問題不是 CAR-T 還是化療，是復發時間點在不在 12 個月內。」 |
| 三線以後 | 「藥證核准跟健保給付條件不一定一樣，講新藥角色時要主動把這個落差講出來。」 |
| FL 腸胃道 | 「部位侷限、沒有全身症狀，本身就是在告訴你這是可以 watch and wait 的惰性族群。」 |
| 無症狀淋巴球增多 | 「第一步是 H&P 排除反應性原因，不是直接跳去講 flow 的 CD5、CD23。」 |

## 容易被電

- 治療反應不理想直接跳去換藥，沒有先想「診斷本身可能要重新確認」（骨架第 3 層）。
- 講三線只丟藥名，沒意識到健保給付限制（骨架第 4 層）。
- 把「CAR-T 是新的二線標準」講成適用所有產品——BELINDA 沒有顯示優勢，效益是 axi-cel、liso-cel 特有。
- 把 salvage ORR 講太樂觀，忽略「反應率 ≠ 能移植的比例」。
- 看到 follicular lymphoma 就急著治，沒有先套 GELF 問「該不該動手」。
